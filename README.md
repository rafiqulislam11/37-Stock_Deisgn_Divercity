### 2. 🛡 Anti-Repetition & Uniqueness Scoring
- Dynamic weighted similarity calculation comparing against active batch and history.
- Adjustable similarity threshold slider (10% high diversity to 70% tight variation).
- Attribute locks to hold specific traits constant while varying others.
- Protected locks to prevent accidental deletion or overwriting of favorite concepts.

### 3. 🏷 Guaranteed 49-Keyword Metadata Engine
- **Exact 49 Marketplace-Compliant Tags**: Free from forbidden symbols (`&`, parentheses, brackets, or pure numbers).
- **Top 5 Priority Tags**: Automatically highlighted to maximize search algorithm weight on Adobe Stock and Shutterstock.
- **Marketplace Taxonomies**: Native category mapping for Adobe Stock and Shutterstock.
- **Character-Safe Commercial Descriptions**: Strict <= 200 character compliance for Shutterstock contributor CSV upload compatibility.
- **Interactive Metadata Inspector**: Live chip cloud, individual tag copy, bulk copy, and inline keywords editing.

### 4. 📥 Multi-Marketplace CSV & JSON Export
- **Adobe Stock Contributor CSV**: Filename, Title, 49 Keywords, Category.
- **Shutterstock Contributor CSV**: Filename, Description, Keywords, Categories, Editorial flag, Illustration flag.
- **Full Dataset CSV**: Complete DNA parameters + Uniqueness score + Metadata + Prompts.
- **Metadata Only CSV**: Titles, descriptions, and 49 keywords.
- **Full Project JSON**: Import and export projects with deduplication and state restoration.

### 5. 📱 100% Responsive on All Devices
- **Mobile Phones (320px - 480px)**: Compact topbar, dedicated 3-tab switcher (`⚙ Settings`, `✦ Results`, `📋 History`), sticky bottom action bar, iOS safe-area inset support, and bottom-drawer modal.
- **Tablets & Foldables (768px - 1024px)**: Adaptive single/double column layout with sticky first-column table scrolling.
- **Desktops & Laptops (1024px - 1440px)**: Sticky sidebar controls + high-throughput multi-column results grid.
- **Ultra-Wide & 4K Displays (1600px+)**: Fluid auto-fill card grid with comfortable maximum width constraints.

### 6. 🎨 Premium UI / UX
- Sleek modern dark mode (default) and crisp light mode toggle.
- HSL-curated color palette, modern typography (Plus Jakarta Sans & Outfit).
- Micro-animations, responsive toasts, and confirmation dialogs.
- 100% private in-browser execution with `localStorage` persistence — zero API keys or external server calls required.

## 🚀 How to Run

Simply open `index.html` in any modern web browser:
- Google Chrome
- Microsoft Edge
- Apple Safari (iOS / macOS)
- Mozilla Firefox

No build tools, Node runtime, or API keys required.

## 📂 Project Architecture

```
├── index.html          # Semantic HTML5 markup with 80-category dual-mode controls, quick pills & modals
├── css/
│   └── style.css       # Unified design system, CSS variables, pills, badges & media queries
├── js/
│   ├── data.js         # 80 Abstract categories, 749 sub-types, general categories & taxonomies
│   ├── metadata.js     # 49-keyword generator, title synthesizer, & character-safe descriptions
│   ├── generator.js    # Design DNA engine, subcategory variation, similarity & prompts
│   ├── storage.js      # Robust localStorage persistence, project export & import
│   ├── csv.js          # Marketplace CSV generators (Adobe Stock, Shutterstock, Full)
│   ├── ui.js           # Card rendering, subcategory tags, toast system & history table
│   └── app.js          # Master controller, mode switching, cascading pickers & events
└── README.md           # Documentation and feature guide
```
